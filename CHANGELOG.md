## [0.1.0] - 2024-01-01

### Added

- Initial release
- `ask` command for read-only agent queries
- `run` command with full tool access
- `models` command to list available models
- `status` command for account/auth info
- `config init` / `config show` for configuration management
- Live Markdown rendering via Rich
- Inline tool-call visualization with `--verbose`
- NDJSON stream parsing
- Config file support at `~/.config/jafat/config.toml`
